# Первое сообщение для Codex

Продолжи существующий проект «ИНСТРАКТ | КСУ Контроль» из этой папки. Сначала прочитай `AGENTS.md`, `README.md` и `CODEX_HANDOFF.md`, затем запусти исходный прототип v1.1 и проверь основной сценарий.

Сейчас приложение — автономный HTML/CSS/JavaScript, данные в localStorage; сохранение между устройствами отсутствует. Данные первой версии переносить не нужно. Нельзя считать переключатель ролей авторизацией.

Наша задача — подготовить **первую рабочую совместную версию на двух пользователей**:
- Эльман со смартфона создаёт выезд, проводит чек-лист, прикладывает фото, регистрирует замечания и отмечает устранение;
- Андрей в другом браузере под своей учётной записью видит те же записи, историю изменений, просрочки и формирует отчёты;
- результаты инвентаризаций импортируются из CSV, затем из XLSX, и агрегируются по объектам, периодам, категориям, количеству, суммам недостач и излишков;
- первичное расхождение не должно автоматически считаться установленным ущербом.

**Сначала:**
1. Проверь структуру текущего кода и тесты, ничего не удаляя.
2. Предложи минимальный план перехода к общему хранению и двум ролям; укажи, какие решения зависят от согласования ИНСТРАКТ.
3. Сделай локально запускаемую демонстрацию полного сценария с двумя разными аккаунтами на тестовых данных. Если доступы к серверу не предоставлены, используй локальный API/БД, не притворяясь, что есть реальная облачная синхронизация.
4. Проверь разделы «План выездов», «Проверки», «Нарушения», «Инвентаризации», «Аналитика», «Недельный отчёт» на компьютере и телефоне.
5. Подготовь понятную инструкцию, как мне запустить и протестировать оба аккаунта.

Требования: сохранить существующий внешний вид и русскоязычный интерфейс, структурировать проект для дальнейшей поддержки, не использовать конфиденциальные данные и не публиковать проект без разрешения. Не требуй от меня знания программирования. Покажи готовые изменения и проверки, а не только советы.
