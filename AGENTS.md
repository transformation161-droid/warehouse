# Инструкции для Codex — ИНСТРАКТ | КСУ Контроль

Сначала прочитай `README.md`, `CODEX_HANDOFF.md` и `CODEX_START.md`.

- Продолжай существующий рабочий прототип v1.1, а не заменяй его другим приложением.
- Интерфейс на русском. Два основных сценария: инспектор (Эльман) — мобильная работа на объекте; руководитель — контроль, аналитика, отчётность.
- Исходная версия автономная и хранит данные в localStorage. Переключатель «Андрей / Эльман» демонстрационный, не авторизация.
- Любые тестовые данные должны быть явно помечены как демонстрационные.
- Не выкладывай корпоративные данные, схемы, ключи или конфиденциальные отчёты в публичный репозиторий.
- Не подключай внешние сервисы и не публикуй рабочую систему без согласования владельца корпоративной инфраструктуры. Для разработки используй фиктивные данные и локальный/макетный API.
- В будущей серверной части обеспечь ограничение доступа на уровне базы (а не только интерфейса), журналирование и резервное копирование.
- Набор новых функций не должен мешать главному сценарию: выезд → чек-лист → нарушение → исправление → отчёт.
- При первом запуске проверь работоспособность текущего проекта и выпиши выявленные проблемы; затем выполняй работу небольшими проверяемыми этапами.
- Изменения после каждого этапа сопровождай тестами и инструкцией проверки для пользователя.
