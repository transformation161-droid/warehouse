ИНСТРАКТ | КСУ Контроль v1.1 — проект для Codex

1) Распаковать архив ksu-control-codex.zip.
2) На компьютере открыть Codex (десктоп-приложение) и выбрать папку ksu-control как проект.
3) Отправить текст из CODEX_START.md. Codex увидит файлы в выбранной папке.

Если используете только Codex Cloud в браузере/на телефоне, обычно удобнее
поместить содержимое папки в ЧАСТНЫЙ репозиторий GitHub и подключить его
к Codex Cloud. Простая отправка ZIP в чат Codex может не создать рабочую
папку проекта. Не публикуйте корпоративную информацию в открытом GitHub.

Исходная версия — прототип без общей БД и без настоящей авторизации.
Данные переносить не требуется, все тестовые данные демонстрационные.
