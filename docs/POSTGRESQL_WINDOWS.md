# Независимая копия PostgreSQL на Windows — без установки Python

Нужен Docker Desktop с Linux-контейнерами и PowerShell 5.1+. Корпоративный рабочий контур не
менять: сначала проверить на синтетической копии. Скрипты не обращаются к Amvera сами по себе.

## Один раз подготовить инструменты, пока есть Интернет

Администратор скачивает исходники этой ветки и в их папке выполняет:

```powershell
docker build -f Dockerfile.postgres -t ksu-postgres:offline .
docker pull postgres:17-bookworm@sha256:839fbb5a4942a7758dd93e18b42ea5649807491a0545b5eeeb8f0b8bb11857a5
```

В Python на Windows нет необходимости: все модули уже внутри образа. Образы можно заранее
перенести через `docker save`/`docker load` в одобренном порядке, без данных/паролей в образах.

## Скачать проверенную копию

Создайте закрытую папку на шифрованном диске (например, BitLocker), вне OneDrive/Git/публичных папок.
Адрес — только разрешённый владельцем PostgreSQL-экземпляр приложения. Пока действующий пилот
остаётся SQLite, новый экспорт на нём не появится автоматически.

```powershell
.\tools\Backup-Postgres.ps1 -Origin 'https://APPROVED-APPLICATION.example/' -Destination 'D:\PrivateKSU\copy.ksubackup'
```

Скрипт запросит login manager и пароль скрытым вводом. Использует действительную TLS-проверку,
cookie/CSRF, потоковый FileStream и сверяет SHA-256. Пароль/токены не сохраняет. Файл создаётся
с доступом текущего пользователя и SYSTEM; существующий файл не заменяется. При ошибке partial
удаляется. Inspector не получает backup. В локальном демонстрационном режиме допустим localhost HTTP.

## Восстановить без исходного сервера и Интернета

Закройте исходное приложение, оставьте доступными только скачанный доверенный пакет, исходники
инструментов и подготовленные Docker-образы. Выполните:

```powershell
.\tools\Restore-Postgres.ps1 -Backup 'D:\PrivateKSU\copy.ksubackup' -Port 8000
```

Скрипт создаёт новые **локальные** контейнеры и тома с уникальными именами. Пакет подключает
read-only; исходный сервер и старые БД не используются. Служебные пароли генерируются в памяти,
передаются как environment без значений в аргументах и восстанавливают прежнюю среду PowerShell.
Схема восстанавливается с checksum-проверкой; API запускается только после успешной проверки.
PostgreSQL не публикует порт наружу, интерфейс доступен только на `http://localhost:8000`.

Войдите прежними паролями manager и inspector: они сохранены в виде хешей, не извлекаются из копии.
Проверьте календарь/план/акты, фото, историю, реестр решений и отчёты; повторный импорт того же файла
не должен создавать строки. Сессии из исходного сервера не действуют.

Команда остановки и имена локальных томов выводятся в конце. Том с данными автоматически не удаляется.
Не отправляйте `.ksubackup`, `.dump`, credentials, сертификаты или корпоративные файлы в GitHub/чат.

Синтаксис проверяется Windows CI. Backend, большая копия и независимый restore проверены в Linux
при 0,5 CPU / 1 ГиБ; приёмку Docker Desktop/BitLocker/ACL на конкретном Windows-компьютере нужно
выполнить по этим шагам. Это не установка или обновление работающей корпоративной системы.
