## Отключение функций и восстановление

После будущего согласованного запуска оперативное отключение —
`KSU_VIEWER_ACCESS=off` и/или `KSU_OFFLINE_MODE=off` на том же v4 binary/БД,
с прежними origin/deployment ID. Сохранять пользователей, ACL, receipts, фото и локальные очереди.
Изменение этих флагов в рабочей среде сейчас не выполняется.

v3 binary нельзя запускать на v4. Старую SQLite нельзя возвращать поверх новых записей:
это потеря данных. Для recovery сначала остановить изменения, получить новую независимую копию
и отдельно согласовать сверку дельты/восстановление. Подробности — [RELEASE_VIEWER.md](RELEASE_VIEWER.md).
