# Выбор размещения для задачи №4

## Решение

Для пилота двух пользователей выбран **Oracle Cloud Always Free: одна VM.Standard.A1.Flex (1 OCPU, 6 GB RAM), Ubuntu 24.04 ARM, boot volume 50 GB + отдельный постоянный block volume 50 GB**. FastAPI и SQLite не меняют архитектуру, фото остаются в закрытой БД. Caddy даёт HTTPS и перенаправляет на API, слушающий только loopback. Бесплатное тестовое DNS-имя можно получить по IP через `sslip.io`; покупать домен не требуется.

Это **кандидат, а не уже арендованный сервер**. Нет подключённого OCI-аккаунта. Владелец сообщил, что регистрацию ещё нужно пройти. Никаких ресурсов в облаке не создано, расходов не было. Известные лимиты ниже нельзя считать договорной гарантией: перед созданием агент обязан проверить актуальные условия, аккаунт, домашний регион, доступную ёмкость и суммарное использование Always Free.

## Сравнение

| Вариант | Постоянное хранение SQLite | Практичность для этого пилота | Решение |
|---|---|---|---|
| Oracle Always Free ARM VM | Boot/block volumes; данные отделены от релизов | Минимум изменений. Обычно лимиты A1 до 4 OCPU/24 GB суммарно, block volumes до 200 GB суммарно. Наш план использует 1/6 и 100 GB. Нужны свободная ёмкость и право на Always Free в home region | Основной вариант, только после живой проверки бесплатности |
| Google Compute Engine Free Tier | Persistent Disk | Маленькая e2-micro в отдельных регионах; отдельно учитывать внешний IPv4, egress и прочие тарифицируемые компоненты. Без проверки всей сметы обещать 0 ₽ нельзя | Не создавать вместо Oracle автоматически |
| Render Free | Эфемерная локальная ФС, бесплатный постоянный диск для SQLite не предоставляется | Перезапуск/переразвёртывание не обеспечивает сохранность SQLite. Бесплатная внешняя БД также имеет тарифные ограничения | Не подходит текущей схеме |
| Fly.io / Railway | Постоянные диски/сервисы зависят от оплачиваемого потребления и условий кредитов | Пробные кредиты не равны бессрочному бесплатному серверу | Не считать вариантом 0 ₽ без отдельного подтверждённого предложения |
| Koyeb Free | Бесплатная VM сама по себе не доказывает бесплатный persistent volume | Потребует сверки хранения и, вероятно, внешней БД | Не выбран: больше изменений/не подтверждён нулевой бюджет |
| GitHub Pages / Cloudflare Pages | Нет постоянно работающего FastAPI с локальной SQLite | Статическая публикация не решает задачу совместного защищённого API | Не подходит |

## Бесплатность: обязательные ограничения перед apply

1. Только Free Tier без перехода в paid/PAYG; владелец самостоятельно проходит регистрацию, MFA и возможную проверку провайдера. Карточные данные/пароли не нужны агенту и не передаются в чат. Если провайдер требует финансовое действие, неприемлемое владельцу, остановиться.
2. Проверить **текущие** Always Free условия и оставшиеся квоты всего аккаунта, а не только этого Terraform-модуля. Подтвердить доступность shape и образа Ubuntu ARM с отметкой eligible. Terraform не является калькулятором стоимости и не умеет доказать оставшиеся квоты по всем существующим ресурсам.
3. Terraform блокирует план по умолчанию (`free_tier_verified=false`) и вне home region. Размеры зафиксированы. Нет платного балансировщика, NAT gateway, Marketplace-образа, managed database, платного домена, платных backup policies или автоматического перехода на другую shape.
4. Отдельный data volume имеет `prevent_destroy`; установка требует именно смонтированный local ext4/xfs volume. Не форматировать существующий том и не удалять boot/data volumes, чтобы «попробовать ещё раз».
5. Лимит исходящего трафика, наличие других дисков, стоимость IP и дополнительные сервисы сверяются до создания. При `out of capacity` не заменять shape платной и не повышать аккаунт до paid.
6. Oracle может отзывать простаивающие Always Free VM; нет SLA/гарантии ёмкости. Не создавать искусственную нагрузку для обхода правил. Сохранять отдельную проверенную копию вне VM и знать порядок восстановления. После замены публичного IP обновить DNS/origin и снова проверить сертификат.

На 1 ноября 2026 в этой среде официальная Oracle-страница вернула proxy `403 Forbidden`; сетевой доступ к прочим тарифным сайтам также не был предоставлен. Поэтому численные лимиты — предварительные ориентиры, **не подтверждённые здесь текущим тарифом**. Доменам документации и `api.github.com` подготовлены добавления в черновике сетевых настроек, но сохранение черновика не применило доступ. Пока актуальная бесплатность/аккаунт/квоты не подтверждены, реальный `terraform apply` запрещён этим планом работ.

Доступные реальные проверки: GitHub issue №4 прочитан; официальный Caddy 2.11.7 скачан с проверкой SHA512; Terraform 1.17.1 — SHA256; OCI provider 9.11.0 прошёл проверку подписи партнёра HashiCorp и зафиксирован lock-файлом. Это доказывает пригодность инструментов/конфигурации, а не бесплатность или готовность внешнего сервера.
