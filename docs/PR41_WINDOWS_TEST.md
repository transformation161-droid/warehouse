# PR41: короткая приёмка на Windows и Android

Приложение строго `cc0b18238fdca4cd02876b5daf0cbef4481c3eb2` — без новых функций.
Комплект добавляет только запуск изолированной вымышленной PostgreSQL17 и тестовые данные.
Нужен запущенный Docker Desktop в режиме Linux containers, около 2 ГБ RAM и несколько ГБ диска.
Первый запуск собирает образ и скачивает зависимости; повторный использует прежние данные.
Никаких Amvera API, внешних PostgreSQL, корпоративных файлов/паролей или платных ресурсов.

## Запуск: скачать ZIP и вставить только команды

Скачать artifact **PR41-Test-cc0b182**, сохранить в Downloads как `PR41-Test-cc0b182.zip`.
Вставлять в PowerShell **только содержимое блока ниже**. Нумерованные пункты задания — обычный
текст для Codex, не команды PowerShell; именно их выполнение вызвало UnexpectedToken.

```powershell
$pr41Zip = Join-Path $env:USERPROFILE 'Downloads\PR41-Test-cc0b182.zip'
$pr41Kit = Join-Path $env:LOCALAPPDATA 'INSTRAKT\PR41-Test-Kit'
Expand-Archive -LiteralPath $pr41Zip -DestinationPath $pr41Kit
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$pr41Kit\Start-PR41-Test.ps1" -TrustTestCA
notepad (Join-Path $env:LOCALAPPDATA 'INSTRAKT\PR41-Test\private\test-accounts.txt')
```

Если kit уже распакован, повторять только последние две команды. Не использовать -Force при
распаковке поверх неизвестной папки. ExecutionPolicy меняется только у запускаемого процесса.
Скрипт проверяет manifest, собирает неизменённый образ PR41, создаёт новые собственные Docker
network/volumes/контейнеры, private-файлы в LocalAppData и выводит **TEST ONLY URL**. Открыть
именно этот URL на ПК: origin/IP/порт должны совпадать. Порты PG не публикуются вообще.

`-TrustTestCA` явно устанавливает **только новый тестовый CA** в Windows CurrentUser\Root;
В стандартном окне Windows «Security Warning» подтвердить установку только INSTRAKT PR41 TEST CA
с отпечатком, выведенным скриптом. Глобальная TLS-проверка не отключается. Сертификат сервера действителен 7 дней, CA — 14.
Ключи и случайные пароли генерируются на вашем ПК, отсутствуют в ZIP/образе/GitHub/CI.
Если корпоративная политика запрещает пользовательские CA, согласовать это с администратором;
не использовать bypass проверки сертификатов. Запуск не меняет системную Execution Policy.

Автоматически выбирается единственный активный аппаратный IPv4 LAN с gateway. Если LAN не
найден, доступ только с ПК через 127.0.0.1. Если адресов несколько, скрипт перечислит их и
попросит выбрать -HostAddress. Просмотр адресов и явный запуск (подставить адрес Wi-Fi ПК):

```powershell
Get-NetIPConfiguration | Select-Object InterfaceAlias,IPv4Address
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$pr41Kit\Start-PR41-Test.ps1" -HostAddress '192.168.1.50' -TrustTestCA
```

Адрес задавать при первом запуске профиля. Менять origin/порт существующего профиля нельзя;
для другого адреса остановить прежний и выбрать новую -DataDirectory вне Git, например
`$env:LOCALAPPDATA\INSTRAKT\PR41-Test-Android`. Это создаёт отдельные вымышленные данные,
не удаляет прежние. Не передавать скрипту рабочие каталоги/БД: таких параметров у него нет.

## Android: тот же Wi-Fi, HTTPS без публичного туннеля

1. ПК и телефон подключить к одной доверенной локальной сети. Открыть на телефоне тот же
   TEST ONLY URL вида `https://192.168.x.x:8041`. Интернет/проброс портов на роутере не нужен.
2. Передать **только** `PR41-Test-CA.crt` из указанной скриптом private-папки по USB. Не копировать
   secrets.json, ключи, env и файл паролей на общие диски/в чат.
3. На Android: Настройки → Безопасность → Шифрование и учётные данные → Установить сертификат
   → Сертификат CA (названия зависят от производителя). Подтвердить локальным PIN, выбрать файл
   INSTRAKT PR41 TEST CA. После установки открыть URL в Chrome без предупреждения о сертификате.
   Если предупреждение остаётся — остановиться, сверить IP/время/сертификат, не обходить TLS.
4. Если Windows Firewall блокирует доступ, вручную разрешить **только** этот порт в Private LAN.
   Ниже необязательная команда в отдельном PowerShell администратора с настоящим IP ПК:

```powershell
New-NetFirewallRule -DisplayName 'INSTRAKT PR41 test 8041' -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8041 -LocalAddress '192.168.1.50' -RemoteAddress LocalSubnet -Profile Private
```

Скрипт не меняет firewall автоматически. Не включать доступ из Public-сетей, не открывать PG,
не настраивать роутер и не создавать публичный туннель. При guest Wi-Fi/client isolation
использовать доверенную домашнюю сеть, не ослаблять рабочие сетевые ограничения.

## Аккаунты и данные

- `demo-manager` — ДЕМО руководитель; два вымышленных склада.
- `demo-inspector` — ДЕМО КСУ; только Склад Север.
- `demo-viewer` — только просмотр Склад Север.

**Пароли** — в открытом Notepad файле `test-accounts.txt`, новые случайные при первом запуске.
После Stop/Start они сохраняются. Демо-пароли нельзя использовать в рабочем приложении.

Данные: 22 исходных вопроса, акт с фото, нарушения «Открыто / В работе / Устранено», четыре
инвентаризации: свежая (5 позиций с длинными названиями/брендом), пример всех четырёх статусов,
закрытая и длинный список 121 позиции. Всё помечено ДЕМО; компания/работники не копировались.

## Пять проверок — около 10 минут

1. **Быстрый пересчёт.** Войти как demo-inspector, открыть «1. Быстрая инвентаризация».
   Галочкой подтвердить первую позицию; красной кнопкой у второй ввести 0, комментарий и фото тестового листа «ДЕМО».
   У третьей (учёт 0) ввести 1 с комментарием. Проверить соответствие, недостачу, излишек и
   оставшиеся непроверенные. Двойной тап не создаёт второй записи. На двух устройствах открыть
   одну строку: второй сохраняющий получает конфликт, его ввод/фото остаются до сверки.
2. **Android.** Крупные кнопки, карточки без горизонтального скролла, выбор фото, дробная
   клавиатура. В списке 121 позиции проверить поиск/страницы/сохранение прокрутки. Перезагрузить:
   сохранённый факт/фото остаются. Закрытый пересчёт не имеет кнопок записи.
3. **PDF/XLSX.** Из «2. Пример четырёх статусов» скачать оба файла. Сверить бренд/статус/единицы
   каждой строки и пустой факт непроверенной. Итоги: план 300.10, известный факт 200.00,
   недостача 200.00, излишек 100.00 (дробная строка ещё не проверена). Проверить печать из Excel.
4. **Фотографии.** Открыть карточку нарушения, фото-подтверждение и акт. Фото увеличивается;
   кнопка/Escape/касание вне фото закрывают только изображение. Повторить как demo-viewer:
   просмотр разрешённого фото есть, кнопок записи нет.
5. **Счётчики.** Manager видит 2 / 4 по обоим складам; inspector/viewer — 2 / 3 на Севере.
   На Юге 0 / 1 должно отображаться явно. Устранить открытое нарушение, приложив фото и результат:
   уменьшается только «Открыто», «Всего» сохраняется; изменение видно на другом устройстве.

Черновики нарушений PR42 не реализуются. До подтверждения записи не закрывать вкладку;
при конфликте сохранять recovery-копию локально. Нельзя очищать очередь/данные рабочей системы.

## Остановка и окончание теста

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$pr41Kit\Start-PR41-Test.ps1" -Action Stop
```

Останавливаются только два контейнера этого профиля. Данные/пароли/CA сохраняются, повторный
Start не выполняет повторный seed и не меняет тестовые записи. Рабочие контейнеры не затрагиваются.
После приёмки удалить установленный **INSTRAKT PR41 TEST CA** на Android через список пользовательских
сертификатов. На ПК удалить только этот сертификат по выведенному скриптом thumbprint, не весь Root.
При добавленном firewall-правиле удалить только `INSTRAKT PR41 test 8041`. Никаких prune/массовых
удалений Docker volumes. Публикация/merge/deploy Amvera этим комплектом не выполняются.
