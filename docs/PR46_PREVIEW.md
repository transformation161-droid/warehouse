# PR46: короткая приёмка аналитики

Это настоящее приложение из PR46 с отдельной PostgreSQL 17, вымышленными данными и новыми случайными тестовыми паролями. Рабочие БД и Amvera не используются. Исходные файлы владельца в комплект не входят. За Q1 нет данных: сводный образец не импортируется.

## Windows

Docker Desktop должен работать в режиме Linux containers. Скачайте артефакт **PR46-Preview** из успешной проверки PR46 «Write-off analytics - targeted acceptance», распакуйте ZIP в новую папку и откройте в ней PowerShell. Вставьте только команду:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start-Writeoff-Preview.ps1 -TrustTestCA
```

При первом запуске собирается образ точного SHA PR; это может занять несколько минут. Windows предложит доверять только новому **INSTRAKT PR46 TEST CA** для текущего пользователя. Команда не меняет Execution Policy системы. При нескольких сетевых адресах скрипт попросит выбрать Wi-Fi: добавьте `-HostAddress 192.168.1.10`, заменив адрес адресом своего ПК.

Скрипт напечатает HTTPS-адрес и путь к `test-accounts.txt`. Логины — `demo-manager`, `demo-inspector`, `demo-viewer`; случайные пароли находятся только в этой локальной папке. Приёмка аналитики — под manager; inspector видит только Север, viewer к аналитике доступа не имеет. Не публикуйте пароли/сертификаты/содержимое private в GitHub.

## Android (если требуется)

ПК и телефон — в одной доверенной Wi-Fi сети. Передайте **только публичный** `PR46-Test-CA.crt` на телефон через USB, установите как тестовый CA и откройте HTTPS-адрес, который напечатал скрипт. При необходимости разрешите входящий TCP 8046 в Windows Firewall **только для частного профиля и своей локальной подсети**. Не открывайте порт на роутере и не отключайте проверку TLS. После проверки удалите тестовый CA на телефоне; на ПК удалите только сертификат с напечатанным отпечатком из хранилища текущего пользователя. Сертификат сервера действует 7 дней.

## Пять проверок (5–10 минут)

1. «Аналитика и отчёты → Аналитика списаний»: Q2 2026, 39 строк, 56 единиц, 356 787,50 ₽ стоимости, 113 827,87 ₽ остаточной. Пять нулевых строк сохранены; разница возмещений +3 164,49 ₽ — предупреждение. Q1: **Нет загруженных данных**, без выдуманного нуля.
2. Клик по объекту → прежний паспорт с проверками/нарушениями и новой аналитикой. Кварталы, причины, типы ТМЦ, МОЛ; комбинация фильтров и «Сбросить». Июльские акты относятся к отчётному Q2.
3. Реестр → строка → данные и версии акта. Уточните дату/исключение события с основанием: исходная дата акта не изменяется. Сбросьте уточнение при необходимости.
4. Выгрузите отфильтрованные строки и сводку XLSX/CSV. «Остальные отчёты» сохранены, скрыт только пункт меню инвентаризаций. Данные прежнего пересчёта остаются в БД.
5. «Загрузить отчёт XLSX»: используйте **DEMO-writeoffs.xlsx**, который находится в локальной папке `private`. Q2 2026; сопоставьте Север/Юг с существующими объектами, подтвердите карту. Повтор той же книги не увеличивает итоги. Для исправленного акта используйте отдельную кнопку замещения → сравнение → подтверждение. Не загружайте «Аналитику инвентаризаций».

Остановка только этого стенда (данные сохранятся):

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start-Writeoff-Preview.ps1 -Action Stop
```

Для нового изолированного набора укажите новую `-DataDirectory` и свободный `-Port`. Скрипт не удаляет и не переиспользует чужие контейнеры, тома или непустые папки.
