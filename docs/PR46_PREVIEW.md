# PR46: короткая приёмка аналитики

Это настоящее приложение из PR46 с отдельной PostgreSQL 17, вымышленными данными и новыми случайными тестовыми паролями. Рабочие БД и Amvera не используются. Исходные файлы владельца в комплект не входят. Для проверки графиков в стенд загружены три **вымышленных построчных** отчёта Q1/Q2/Q3 2026: 48 строк, 68 единиц, 616 787,50 ₽ стоимости. Сводный образец владельца не импортируется. В рабочем приложении квартал появится только после загрузки его исходного отчёта.

## Windows

Docker Desktop должен работать в режиме Linux containers. Скачайте артефакт **PR46-Preview** из успешной проверки PR46 «Write-off analytics - targeted acceptance», распакуйте ZIP в новую папку и откройте в ней PowerShell. Вставьте только команду:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start-Writeoff-Preview.ps1 -TrustTestCA -Port 8048 -DataDirectory "$env:LOCALAPPDATA\INSTRAKT\PR46-Reimbursements"
```

Новый стенд использует отдельную папку PR46-Reimbursements и порт 8048; предыдущий комплект/его данные остаются на месте. При первом запуске собирается образ точного SHA PR; это может занять несколько минут. Windows предложит доверять только новому **INSTRAKT PR46 TEST CA** для текущего пользователя. Команда не меняет Execution Policy системы. При нескольких сетевых адресах скрипт попросит выбрать Wi-Fi: добавьте `-HostAddress 192.168.1.10`, заменив адрес адресом своего ПК.

Скрипт напечатает HTTPS-адрес и путь к `test-accounts.txt`. Логины — `demo-manager`, `demo-inspector`, `demo-viewer`; случайные пароли находятся только в этой локальной папке. Приёмка аналитики — под manager; inspector видит только Север, viewer к аналитике доступа не имеет. Не публикуйте пароли/сертификаты/содержимое private в GitHub.

## Android (если требуется)

ПК и телефон — в одной доверенной Wi-Fi сети. Передайте **только публичный** `PR46-Test-CA.crt` на телефон через USB, установите как тестовый CA и откройте HTTPS-адрес, который напечатал скрипт. При необходимости разрешите входящий TCP 8048 в Windows Firewall **только для частного профиля и своей локальной подсети**. Не открывайте порт на роутере и не отключайте проверку TLS. После проверки удалите тестовый CA на телефоне; на ПК удалите только сертификат с напечатанным отпечатком из хранилища текущего пользователя. Сертификат сервера действует 7 дней.

## Пять проверок (5–10 минут)

1. «Аналитика и отчёты → Аналитика списаний»: сразу после KPI — **Графики аналитики**: три квартала, сравнение Север/Юг, причины/типы ТМЦ. Проверьте показатель, Топ-5/10/все и выделение линии. У Юга Q1 отсутствует, а Q3 — подтверждённый ноль. Выберите Q2 2026: 39 строк, 56 единиц, 356 787,50 ₽ стоимости, 113 827,87 ₽ остаточной. Пять нулевых строк сохранены; «К возмещению» 113 827,87 ₽ и «Фактически возмещено» 116 992,36 ₽ — два самостоятельных поля, без разницы или предупреждения. Выберите Q4: **Нет загруженных данных**, без выдуманного нуля. Синтетические Q1/Q3 используются только в этом изолированном стенде.
2. Клик по линии/легенде объекта → прежний паспорт с проверками/нарушениями, компактным квартальным трендом и диаграммой причин. Кварталы, причины, типы ТМЦ, МОЛ; комбинация фильтров и «Сбросить». Июльские акты относятся к отчётному Q2.
3. Реестр → строка → данные и версии акта. Уточните дату/исключение события с основанием: исходная дата акта не изменяется. Сбросьте уточнение при необходимости.
4. Выгрузите отфильтрованные строки и сводку XLSX/CSV. «Остальные отчёты» сохранены, скрыт только пункт меню инвентаризаций. Данные прежнего пересчёта остаются в БД.
5. «Загрузить отчёт XLSX»: используйте **DEMO-writeoffs.xlsx**, который находится в локальной папке `private`. Q2 2026; сопоставьте Север/Юг с существующими объектами, подтвердите карту. Повтор той же книги не увеличивает итоги. Для исправленного акта используйте отдельную кнопку замещения → сравнение → подтверждение. Не загружайте «Аналитику инвентаризаций».

Остановка только этого стенда (данные сохранятся):

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start-Writeoff-Preview.ps1 -Action Stop -DataDirectory "$env:LOCALAPPDATA\INSTRAKT\PR46-Reimbursements"
```

Для нового изолированного набора укажите новую `-DataDirectory` и свободный `-Port`. Скрипт не удаляет и не переиспользует чужие контейнеры, тома или непустые папки.
