# PR 40: Инвентаризация — план, пересчёт и акт

**Статус: Draft.** Основа — PR 39 / SHA 929ce961632bca99265ebc890d49c111a13537e3.
Никаких изменений рабочей Amvera или PostgreSQL до отдельной приёмки.

## Рабочий процесс

1. Руководитель КСУ выбирает объект и дату, загружает Excel/CSV с планом инструментов.
2. Предпросмотр распознаёт заголовки ниже первой строки, сопоставляет поля, проверяет ID, цены и количество, сообщает ошибки с номерами строк. Реальные источники никогда не попадают в GitHub.
3. КСУ проводит пересчёт: пустой факт = «Не проверено», факт 0 = «Не найден», факт 1 = «Найден». Для групповых ТМЦ возможны другие неотрицательные количества. Поддерживаются частичный пересчёт, комментарий, фото и обнаруженные сверх плана позиции.
4. После проверки всех строк руководитель завершает акт; исправления после утверждения только через историю с причиной.
5. Карточка даёт PDF/XLSX: план, факт, отклонение, закупочная цена за единицу, отдельные недостачи и излишки, итоги, дата, объект, поля для подписей.

## Денежные правила

- Плановая стоимость = сумма(учёт × закупочная цена).
- Известная фактическая стоимость = сумма(проверенный факт × закупочная цена).
- Недостача = max(учёт − факт, 0) × закупочная цена.
- Излишек = max(факт − учёт, 0) × закупочная цена.
- Непроверенные позиции не участвуют в расчёте расхождений. Суммы округляются по каждой строке до копеек.
- Не делать взаимозачёт разных позиций. Остаточная стоимость и подтверждённый ущерб не рассчитываются.
- До полного завершения итог предварительный.

## Входной тест

69 индивидуальных инструментов; в XLSX названия колонок на строке 4,
первая колонка пустая, есть «ID», «Наименование», «№», «Стоимость», «Склад».
Все 69 записей после загрузки должны иметь факт null, а не 0 или 1.
В тестах используются только синтетические данные.

## Реализовано в этой ветке

- server/inventory_plan.py — разбор плана XLSX/CSV и read-only preview.
- server/inventory_statement.py — расчёт раздельных расхождений и отчёты XLSX/PDF.
- server/app.py — защищённые read-only маршруты предпросмотра и экспорта с разграничением доступа к объектам.
- release_online/app.js — кнопки скачивания XLSX/PDF в карточке.
- tests/test_inventory_plan.py и tests/test_inventory_statement.py — синтетические проверки.

**Существующая система пока не выполняет полный импорт и последующий пересчёт.**
