ИНСТРАКТ · КСУ Контроль — совместный тестовый пилот

1. Откройте README.md: в разделе «Запуск на компьютере» есть команды для вашей системы.
2. Первичная команда init-demo --generate создаст два тестовых аккаунта.
   Их логины и пароли будут в var/demo-accounts.txt. Не отправляйте этот файл в Git.
3. Запустите сервер командой из README.md, затем откройте http://localhost:8000.
4. В обычном окне войдите как manager, в приватном — как inspector.
5. В README.md выполните раздел «Проверка без программирования».

База общая; данные сохраняются на сервере. Работайте только с тестовыми записями.
Для телефона с отдельного устройства нужен согласованный HTTPS-сервер.
Подготовка размещения и резервное копирование: docs/DEPLOY.md.
Результаты аудита и ограничения: docs/AUDIT.md.
Внешние сервисы не подключены, приложение никуда не опубликовано.
